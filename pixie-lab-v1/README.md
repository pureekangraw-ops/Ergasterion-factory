# PIXIE LAB — compatibility path

`pixie-lab-v1/` is the current implementation path kept for compatibility while ERGASTERION is migrated to the Idea Workspace model.

PIXIE LAB is a department inside ERGASTERION, not the whole application.

Current capabilities in this path include experiment rooms, Idea/Experiment/Variant state, logic drafts, app prototypes, visual experimentation, image-action readback, testing, evidence, regression, persistence, and command routing.

The folder name remains unchanged until compatibility tests and runtime readback are complete.

Use the repository root README as the current application contract.

```bash
npm test
npm run pixie -- status
npm run pixie -- capabilities
```
